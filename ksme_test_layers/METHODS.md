# 다층 초음파 부양 액적 필터 — 해석 방법론

작성 도구: FEniCSx (DOLFINx 0.11) · gmsh 4.15 · NumPy/SciPy · Matplotlib

대상: 40 kHz 초음파로 부양시킨 물 액적 **60개**(10 기둥 × 6 액적, 4 layer 엇갈림 배열)를
필터로 사용하여 10 µm 미세입자를 포함한 공기 유동에서 입자를 흡착시키는 시스템.

기준 장치: **TinyLev** (Marzo, Barnes & Drinkwater, *Rev. Sci. Instrum.* **88**, 085105, 2017)
— 40 kHz, 직경 10 mm 트랜스듀서 72개(면당 36개 = 3링 6/12/18, 중앙 제외),
저전압(~20 V) 구동, 소비전력 10 W, 2.2 g/cm³·4 mm 물체 부양.

---

## 0. 무엇을 왜 이렇게 풀었는가 (해석 전략)

요구사항은 세 가지였다.

1. 액적에 걸리는 힘 — 중력 · 초음파 · 유동
2. 액적 통과 전후 미세입자 농도 비교로 흡착율 산출
3. 유속 5단계 / 초음파 세기 5단계 × 각 5회 반복
4. 단일 액적이 아니라 **60개 액적 4-layer 배열**

여기서 결정적인 제약은 **규모 차이**다. 덕트는 210 × 32 × 360 mm 인데 액적은 2 mm 이고,
액적 표면 경계층은 δ ≈ D/√Re ≈ 0.14 mm 다. 이걸 한 메시로 풀면 자유도가 10⁸ 급이 되어
3D 정상 Navier–Stokes 직접해법(LU)으로는 계산이 불가능하다.

그래서 **규모 분리(multi-scale decomposition)** 를 썼다.

| 규모 | 무엇을 | 어떻게 |
|---|---|---|
| 장치 규모 (10⁻¹ m) | 720개 트랜스듀서의 음향장, 60개 액적의 트랩 | Rayleigh–Sommerfeld 해석적 중첩 (FEM 불필요) |
| 기둥 규모 (10⁻² m) | 액적 6개가 연직 정렬된 단위셀 유동 | 3D 정상 N-S, Taylor–Hood P2/P1, Newton+MUMPS |
| 액적 규모 (10⁻³ m) | 개별 액적 항력, 입자 포집 | 표면 응력적분 + Lagrangian 입자 추적 |
| 배열 규모 | layer 를 지나며 농도가 줄어드는 과정 | 포집 단면적 기반 캐스케이드 모델 |

**연결 고리는 '포집 단면적' A_cap 이다.** A_cap 은 덕트 크기와 무관한 액적 고유의 물리량
이므로, 단위셀에서 한 번 구하면 어떤 배열/덕트로도 이전할 수 있다.

## 1. 지배방정식

### 1.1 액적에 작용하는 세 힘

**(a) 중력 — 상수**

```
F_g = m_d g = ρ_w (π/6) D³ g
```
`ρ_w = 1000 kg/m³`, `D = 2.0 mm` → `m_d = 4.19 mg`, `W = 41.09 µN` (액적 1개)

**(b) 초음파 복사력 — Helmholtz 방정식 + Gor'kov 포텐셜**

정상 음향장은 Helmholtz 방정식을 따른다.
```
∇²p + k²p = 0 ,   k = ω/c₀ = 2π/λ ,   λ = 8.575 mm
```
각 트랜스듀서를 원형 피스톤 소스로 보고 자유공간 Green 함수를 소스면 위에서
적분(Rayleigh–Sommerfeld)한 형태로 **720개 소자를 한 번에 중첩**한다.
```
p(r) = Σ_j  P₀ · D(θ_j) · Ω(θ_j) / d_j · exp( i(k d_j + φ_j) )
D(θ) = 2 J₁(k a_t sinθ) / (k a_t sinθ)      (원형 피스톤 지향성)
Ω(θ) = (1 + cosθ)/2                          (Rayleigh–Sommerfeld 경사인자)
```
- `a_t = 5 mm`, `k a_t = 3.664` → **첫 영점이 가시영역 밖**이라 10 mm 트랜스듀서는
  지향성이 약하다(θ=90°에서 D = 0.218). 그래서 유닛 간 간섭을 무시할 수 없고,
  10대를 모두 한꺼번에 중첩해야 한다.
- 경사인자 `Ω(θ)` 는 필수다. 예전처럼 θ>90°를 0으로 자르면 **불연속**이 생겨
  `∇p`, `∇U_G` 에 단일 격자점 스파이크가 나고 트랩 힘이 수 배 틀린다(§6 V-0).

반경 `a` 구가 받는 시간평균 복사력은 Gor'kov 포텐셜의 음의 기울기다.
```
U_G = (4/3)π a³ [ f₁ · (1/2) κ₀ ⟨p²⟩  -  f₂ · (3/4) ρ₀ ⟨|v|²⟩ ]
f₁ = 1 - κ_p/κ₀ ,      f₂ = 2(ρ_p - ρ₀)/(2ρ_p + ρ₀)
⟨p²⟩ = |p|²/2 ,        ⟨|v|²⟩ = |∇p|² / (2(ωρ₀)²)
F_ac = -∇U_G
```

> **주의 (실수하기 쉬운 곳).** `U_G` 는 `|∇p|²` 를 포함하므로 **한 직선 위에서
> 그 직선 방향 미분만으로는 계산할 수 없다.** 트랩 높이에서 x 방향으로 훑으면
> 지배적인 `∂p/∂z` 성분이 통째로 빠져 횡방향 복원력이 0 에 가깝게 나온다.
> 본 해석은 직선 주위에 두께 3점(±20 µm)의 얇은 3D 슬랩을 만들어 `∇p` 를 온전히
> 구한 뒤 중앙선의 `U_G` 를 다시 미분한다 (`acoustics_layers.gorkov_along`).

**구동 세기 의존성.** 음압은 인가전압에 비례(`p₀ ∝ V`)하고 전류도 전압에 비례하므로
전기 입력전력 `∝ V²` 이다. `U_G ∝ p₀²` 이므로
```
F_ac(V) = (V/V₀)² · F_ac(V₀)
```
이 관계로 구동 5단계를 기준장 1회 계산에서 해석적으로 스케일한다.

**(c) 유동에 의한 힘 — 비압축성 Navier–Stokes**
```
ρ_a (u·∇)u = -∇p + µ ∇²u        (정상 상태)
∇·u = 0
```
액적 k 가 받는 힘은 응력텐서를 그 액적 표면에서 적분해 얻는다.
```
σ = -p I + µ(∇u + ∇uᵀ)
F_k = -∮_{S_k} σ·n dS
```
압력항과 점성항을 분리 계산해 형상항력/마찰항력 비중을 정량화한다.

### 1.2 미세입자 운동 — 뉴턴 운동방정식 + 항력

```
m_p dv/dt = F_drag + F_grav + F_ac,p
dx/dt = v

F_drag = 3π µ d_p (u_f - v) · f(Re_p),   f = 1 + 0.15 Re_p^0.687   (Schiller–Naumann)
F_grav = m_p g (1 - ρ_a/ρ_p)
F_ac,p = -∇U_G |_(a = d_p/2)              (drive² 로 스케일)
Re_p   = ρ_a |u_f - v| d_p / µ
```
`τ_p = ρ_p d_p²/(18µ) = 0.614 ms`, `St = τ_p U / D`.
입자에 걸리는 음향 복사력은 최대 7.25 pN 으로 입자 무게(10.27 pN)의 71 % 이지만,
항력 대비로는 슬립속도 4 mm/s 에 해당해 유속(m/s 급)의 0.3 % 미만이다. 그래도
계산에는 포함시켰다.

## 2. 설계 — 배열 형상을 어떻게 정했는가

### 2.1 기둥 1개에 액적이 왜 6개인가

TinyLev 두 배열의 정점 간격은 99.8 mm(논문 ~10 cm 와 일치)이고, 축 위 음압은
집속빔 간섭으로 정재파를 만든다. 계산된 압력 노드는
```
z = ±2.34, ±7.03, ±11.74, ±16.50, ±21.32 mm
```
**노드 간격이 4.68–4.82 mm 로 평면파 λ/2 = 4.288 mm 보다 9 % 크다.** 집속빔의
Gouy 위상 때문이며, 액적 기둥 전체 높이를 정하는 실질적인 값이다.

각 노드의 트랩 용량(그 노드가 낼 수 있는 최대 상향력)은
```
±2.34 mm : 1.59 W      ±7.03 mm : 1.56 W      ±11.74 mm : 1.40 W
±16.50 mm : 1.14 W     ±21.32 mm : 0.81 W  (< W → 부양 불가)
```
중앙 6개 노드가 여유 1.28–1.59 W 로 확실히 잡히므로 **기둥당 액적 6개**로 정했다.
이때 기둥 높이는 23.5 mm 이고, 덕트 높이 32 mm 에서 벽까지 여유가 3.27 mm (1.64 D) 다.

### 2.2 기둥 10개를 왜 이렇게 배치했는가

트랜스듀서 배열의 외경은 **65.2 mm** (외곽링 반경 27.6 mm + 트랜스듀서 반경 5 mm)이다.
두 부양기가 물리적으로 겹치지 않으려면 축 간 거리가 65.2 mm 이상이어야 한다.

엇갈림 4-layer (3-2-3-2 = 10 기둥)로 배치하면
```
layer 간격 S_x = 60 mm,  같은 layer 내 기둥 간격 S_y = 70 mm
최소 축간거리 = √(S_x² + (S_y/2)²) = 69.5 mm > 65.2 mm   ✓
```
- layer 1 (x=0)   : y = -70, 0, +70 mm      (3 기둥 = 18 액적)
- layer 2 (x=60)  : y = -35, +35 mm         (2 기둥 = 12 액적)
- layer 3 (x=120) : y = -70, 0, +70 mm      (3 기둥 = 18 액적)
- layer 4 (x=180) : y = -35, +35 mm         (2 기둥 = 12 액적)

덕트는 **210(W) × 32(H) mm** (A = 6720 mm², D_h = 55.5 mm). 폭은 기둥 1개당 S_y = 70 mm
를 담당하도록 3 S_y 로 잡았다.

### 2.3 덕트와 부양기의 직결 (멤브레인 없음)

액적이 미세입자를 다량 흡착하면 교체해야 하므로, 개구를 음향투과 멤브레인으로
덮을 수 없다. **덕트 천장/바닥에 원형 개구를 내고 부양기 하우징(넥)으로 직접
연결한다.**

**개구 반경을 20 mm 로 정한 근거.** 두 배열은 초점을 향해 집속하므로, 배열이
65.2 mm 로 넓어도 덕트 벽면(z = ±16 mm)에서 빔은 훨씬 좁다. 가장 바깥 트랜스듀서
가장자리(ρ = 32.6 mm, z = 49.9 mm)에서 초점으로 가는 직선이 z = 16 mm 를 지나는
반경은
```
r_beam = (ρ_t + a_t)·z_w/z_t = 10.45 mm
```
이다. 따라서 `R_OPEN = 20 mm` 면 빔 반경의 **1.9 배** 여유가 있어 음향장이 사실상
그대로 유지되고, 직경 2 mm 액적의 투입·회수(개구 ∅40 mm)도 넉넉하다.
배열 외경만큼(65.2 mm) 뚫을 이유가 없다.

```
개구 반경 R_OPEN = 20 mm       넥 길이  NECK_H = 37.4 mm  (z = 16 → 53.4 mm)
넥 천장   = 트랜스듀서 배열면 (음향 초점 중심 반경 57 mm 구면)
넥 부피   = 49.3 cm³ / 개      (부양기 1대당 상·하 2개)
```

인접 챔버가 겹치지 않을 것: 최소 기둥 중심거리 69.5 mm > 2·R_OPEN = 40 mm ✓

**액적 교체**: 개구를 통해 위/아래로 액적을 넣고 뺄 수 있다. 해당 부양기의 구동을
잠깐 끄면 액적이 아래 개구로 떨어져 회수된다.

## 3. 수치 방법

| 항목 | 방법 |
|---|---|
| 음향장 | Rayleigh–Sommerfeld 해석적 중첩 (720 소자), NumPy 벡터화 |
| Gor'kov | 직선 주위 3점 두께 3D 슬랩으로 `∇p` 전 성분 → `U_G` → `F = -∇U_G` |
| 유동 | 정상 비압축성 N-S, Taylor–Hood **P2/P1** 혼합요소 |
| 비선형 해법 | Newton (PETSc SNES) + backtracking line search, 유속 연속법 4단계 |
| 선형 해법 | 직접 LU (MUMPS), OMP 6 스레드 |
| 입자 | Lagrangian **RK4**, dt = min(0.20 τ_p, 0.05 D/U) |
| 속도장 평가 | **하이브리드 프로브** — 액적 2 mm 이내는 FE 직접 평가, 그 밖은 3단 계층격자 보간 |
| 음향력 보간 | 입자용 Gor'kov 힘을 0.5 mm 격자에 사전계산 후 삼선형 보간 |
| 메시 | gmsh OCC, 액적면 거리기반 세분화 + 기둥/후류 박스 세분화 |

### 3.1 단위셀과 대칭성 (계산량 1/4)

기둥 1개 주위 유동을 해상한다. 두 개의 거울대칭면을 쓴다.

- **y = 0** : 기둥 축을 포함하는 면 → `u_y = 0`
- **z = 0** : 기둥 중앙면 → `u_z = 0`

액적 6개의 평형 위치는 중력 처짐 때문에 정확히 대칭은 아니다
(`z = -12.375 … +11.109 mm`, 무게중심 -0.553 mm). 그래서 **덕트 중심을 액적 기둥의
무게중심에 맞추고** 위치를 상하 대칭화했다.
```
CFD 액적 위치 z = ±2.3248, ±7.0168, ±11.7295 mm   (덕트 중심 기준)
대칭화 오차 최대 67 µm = 0.034 D   (무시 가능)
기둥 간 편차 3–16 µm               (무시 가능)
```
따라서 1/4 도메인에는 **반구 3개**만 들어간다.

```
x ∈ [-8, +24] mm,  y ∈ [0, 7] mm,  z ∈ [0, 16] mm
```

| 경계 | 조건 |
|---|---|
| 입구 x = -8 mm | `u = (u_in(z), 0, 0)`, 1/7 승 법칙 |
| 출구 x = +24 mm | 무응력 (자연 경계조건) |
| y = 0 | `u_y = 0` (대칭) |
| y = 7 mm | `u = (u_in(z), 0, 0)` (원방; 실제 이웃 기둥은 35 mm = 17.5 D 밖) |
| z = 0 | `u_z = 0` (대칭) |
| z = 16 mm | `u_z = 0` (덕트 벽, **자유활동**) |
| 액적면 ×3 | `u = 0` (무활동), **액적마다 별도 태그** → 개별 항력 적분 |

**덕트 벽에 무활동 대신 자유활동을 쓴 이유.** 덕트 `Re_Dh = 1.8×10³ ~ 9.2×10³` 로
천이/난류인데 정상 층류 해석에서 무활동 벽을 두면 실제보다 두꺼운 층류 경계층이
자란다. 대신 입구에 **1/7 승 법칙 난류 코어 프로파일**
```
u(z) = U_bulk · (n+1)/n · (1 - |z|/h)^(1/n),   n = 7   (중심속도 = 1.143 U_bulk)
```
을 주고 벽은 자유활동으로 두었다. 액적 스케일 `Re_d = 66 ~ 331` 은 층류이므로
액적 주위 유동은 그대로 직접 해상된다. 이 처리로 액적 level 별 접근속도가
```
z = ±2.33 mm → 1.118 U   ±7.02 mm → 1.052 U   ±11.73 mm → 0.946 U
```
로 달라지는 것이 자동으로 반영된다 (바깥 액적일수록 느린 유동을 만난다).

**액적면에 무활동을 쓴 근거**: 물/공기 점성비가 55 이므로 액적 내부 순환에 의한
표면 유동은 무시할 수 있다(Hadamard–Rybczynski 보정 < 2 %).

### 3.1b 넥(막다른 공동)의 처리 — 왜 격자로 뚫지 않았는가

넥을 실제로 격자에 뚫고 정상 Navier–Stokes 를 풀어 보았으나 **수렴하지 않았다.**

- 개구 지름 기준 `Re_D = ρU(2R_OPEN)/µ = 1.3×10³ ~ 6.6×10³`. 이 영역에서 개방형
  공동 위 전단층은 본질적으로 **비정상**이라 정상해가 존재하지 않을 수 있다.
- 실제로 `Re_d ≲ 70` 에서는 Newton 이 1회 반복으로 수렴하지만, `Re_d ≳ 100` 부터
  잔차가 10⁻²~10⁻¹ 에서 정체한다.
- 시도한 대책: Stokes 사전해(도움됨) · 유속 연속법 4→6단계 세분화 · MUMPS 반복개선
  (`icntl_10 = 5`) · **grad-div 안정화**(잔차 4배 감소) · **SUPG**(야코비안이 조밀해져
  1케이스 13분 초과, 비용 과다) · 덕트 벽 무활동. 모두 정체를 해소하지 못했다.

**채택한 모델링**: 막다른 공동은 **순 질량교환이 0** 이므로, 그 시간평균 효과로서
개구면을 **자유활동 평면**(`u_z = 0`, 전단응력 0)으로 두고 주유동을 푼다.

- 근거 검증: 넥을 뚫은 형상에서 실제로 잰 개구 통과 유량은 **직관 유량의 0.21 %**
  (U = 1.5 m/s) 였다. 주유동에 대한 영향이 무시할 수준임을 확인했다.
- 넥으로의 입자 유입과 트랜스듀서 오염은 별도 모델(`neck_model.py`)로 다룬다.
  중력 침강(주 경로, 유속 무관)과 전단층 교환(상·하한)을 나누어 정량화한다.
- `mesh_column.build(neck=True)` 로 넥을 뚫은 형상도 만들 수 있게 남겨 두었다.

### 3.2 입자 속도장 평가 — 하이브리드 프로브

RK4 매 단계마다 DOLFINx 셀 탐색을 하면 그 비용이 전체를 지배한다(사례당 15분 이상).
반대로 순수 격자 보간은 **액적 표면 경계층(δ ≈ 0.14 mm)을 담지 못해** 표면 근방
속도를 과대평가한다.

그래서 궤적 중 액적 근방(중심에서 2 mm 이내, 전체 평가의 약 9 %)만 FE 직접 평가하고
나머지는 3단 계층격자(800 / 250 / 80 µm)로 보간한다.

- 격자점 중 **액적 내부는 u = 0 으로 채운다** (무활동 조건과 정합). 자유류로 채우면
  표면 바로 바깥 보간이 오염된다.
- 도메인 밖(상류/하류/측면)은 입구 프로파일로 채운다.
- 질의 시 y, z 를 거울대칭으로 펼치고 `u_y`, `u_z` 부호를 뒤집는다.

검증: 전 구간 FE 직접 평가와 비교해 포집 개수 차이 1.5 % (통계오차 4 % 이내), 속도 5배.

### 3.3 layer 간 결합

- **후류 속도결손**: 단위셀 해에서 x = 5 … 20 mm 의 결손을 측정하고 층류 후류
  상사해 `δ ∝ 1/x` 로 적합해 하류 layer 위치까지 외삽한다.
  엇갈림 배열이므로 정렬된 짝은 layer 1↔3, 2↔4 뿐이고 그 간격은 2 S_x = 120 mm 다.
  layer 2 는 layer 1 로부터 y 로 35 mm (17.5 D) 벗어나 후류 밖이다.
- **횡방향 혼합**: 난류확산계수 `ε_t ≈ 0.07 u* D_h/2 ≈ 1.3×10⁻⁴ U` 로 layer 간격
  60 mm 를 지나는 동안 퍼짐 폭이 `√(2 ε_t t) ≈ 4 mm` 다. 포집 유관 반경(~1 mm)보다
  훨씬 크므로 **완전혼합 가정이 타당**하다(비혼합 하한도 함께 계산해 확인).

## 4. 흡착율(농도차) 산출 방법

액적 1개가 유동에서 제거하는 입자량을 **포집 단면적** `A_cap` 으로 정량화한다.

```
단일 액적 포집효율   η    = A_cap / (π a²)
기둥 1개 포집 단면적 A_col = Σ_{level j} A_cap,j
layer L 제거율       f_L  = (부양 성공 액적의 A_cap 합) / A_duct
layer 통과 후 농도          C_{L+1} = C_L (1 - f_L)
전체 통과율                 C_out/C_in = Π_L (1 - f_L)
전체 흡착율                 E = 1 - C_out/C_in
```

두 방법을 모두 계산해 **상호 검증**한다.

**(A) 적응형 중요도 표본추출** — 주 결과
1. 예비: 각 액적 주위 반경 `R₀ = 1.75 a` 원판에 240개를 뿌려 포집 반경 `r_cap` 과
   포집된 입자의 시딩 중심(중력 침강으로 액적 중심에서 벗어난다)을 개산한다.
2. 본: 반경 `R = clip(2.6 r_cap + 0.15 mm, 0.5a, R₀)` 원판을 그 중심에 맞춰
   액적당 1200개를 뿌린다.
```
A_cap = (N_cap / N_s) · π R² ,   표준오차 = √(q(1-q)/N_s) · π R²
```
저유속(U = 0.5 m/s)에서는 포집 반경이 0.15 mm 수준이라 고정 반경으로 뿌리면
99 % 가 낭비된다. 적응형으로 바꿔 통계오차를 **4배** 줄였다.
안전점검으로 "포집된 입자의 시딩 반경이 0.9 R 을 넘는 비율"을 함께 기록한다(전 조건 0).

**(B) 직접법** — 검증용. 단위셀 입구 단면(14 × 32 mm = 448 mm²)에 4000개를 균일 시딩해
통과 개수를 센다. 요청한 "입구/출구 직접 비교"에 해당하지만, 액적 정면 면적이
단면의 4 % 뿐이라 통계오차가 (A) 의 4~6배다.

**부양 성공 판정.** 액적이 필터로 작동하려면 두 조건을 모두 만족해야 한다.
```
축방향 : F_cap · (V/V₀)² > W                 (중력 지지)
횡방향 : F_esc,x · (V/V₀)² > F_drag          (유동에 의한 이탈 방지)
```
불안정한 액적은 `f_L` 합산에서 제외된다.

**부가 산출량**: 압력손실 `ΔP = N_col · F_drag,col / A_duct`,
청정공기공급률 `CADR = Q · E`, 포집 질량유량, 액적 질량 증가율,
목표 제거율에 필요한 layer 수.

## 5. 실험계획 (DOE)

### 실험 1 — 유속 5단계 (초음파 구동 100 % 고정)
```
U ∈ {0.5, 1.0, 1.5, 2.0, 2.5} m/s
   Re_d  =  66 / 133 / 199 / 265 / 331
   Re_Dh = 1841 / 3682 / 5523 / 7364 / 9205
   St    = 0.153 / 0.307 / 0.460 / 0.614 / 0.767
   Q     = 202 / 403 / 605 / 806 / 1008 L/min
```

### 실험 1·2 를 합친 운전 지도

두 실험을 조합하면 (유속 × 구동세기) 5×5 격자에서 부양 성공 액적 수와 흡착율을
재구성할 수 있다(`make_report_layers.operating_map`). 유동해는 유속에만, 음향력은
구동세기에만 의존하므로 두 축이 분리되기 때문이다. 이 지도가 설계 결론을 준다.

### 실험 2 — 초음파 구동 5단계 (유속 1.5 m/s 고정)
```
V/V₀ ∈ {0.70, 0.85, 1.00, 1.15, 1.30}
→ p₀  ∈ {1680, 2040, 2400, 2760, 3120} Pa
→ 전기 입력전력비 ∝ V² = {0.49, 0.72, 1.00, 1.32, 1.69}
```
부양 임계를 감싸도록 설계했다.

**실험 2 에서 유동해를 재사용하는 근거**: 초음파장이 유동에 주는 영향은 음향
스트리밍이며, Rayleigh 스트리밍 속도는 `(3/16) u_ac²/c₀ ≈ 20 mm/s` 로 운전 유속의
1 % 미만이다. 따라서 단방향 결합(음향 → 힘)만 고려하고 유동해를 재사용한다.

### 반복 — 조건당 독립 실현 5회

유동 솔버는 결정론적이라 같은 조건을 5번 풀면 같은 값이 나온다. 따라서
**독립적인 5개 실현**으로 반복해 표준편차에 **이산화 오차와 몬테카를로 오차를 함께**
반영한다.
```
실현 k = (메시 k, 입자 난수시드 k)
메시 공칭 셀크기 h ∈ {124, 132, 140, 148, 156} µm  (±12 %)
셀 수 71,840 / 61,418 / 53,086 / 46,473 / 41,041   (자유도 33만 ~ 19만)
난수시드 ∈ {1000, 2000, 3000, 4000, 5000}
```

### V-3 — 기존 단일 액적 연구(ksme_test)에서 발견한 오류

새 코드의 단일 액적 포집효율이 기존 연구값의 절반으로 나와 원인을 추적한 결과,
**기존 연구 쪽에 버그**가 있었다.

기존 `particles.VelocityProbe` 는 반(半)도메인(y ≥ 0) FE 해를 y < 0 으로 **미러링하지
않고**, 도메인 밖이라는 이유로 자유류 `(U, 0, 0)` 을 돌려준다. 그 결과 입자의 절반이
균일류를 직진해 액적에 그대로 충돌했다. 기존 값은 다음과 같이 정확히 재구성된다.

```
A_cap(기존) = (1/2)·πa²          (y<0 : 균일류 직진 → 기하학적 차단면)
            + (1/2)·A_cap(정확)  (y>0 : 정상 유동)
            = 1.571 + 0.567 = 2.137 mm²
기존 실측  = 2.166 mm²           (차이 1.3 %)
```
→ **기존 단일 액적 연구는 흡착율·η 를 1.93 배 과대평가**했다
(재구성값 2.132 mm² vs 기존 실측 2.166 mm², 차이 +1.6 %).

정확값(미러링 적용)은 `η = 0.357 @ U = 1.5 m/s` 이며, 고전 관성충돌 상관식
```
(St/(St+0.5))² = 0.230   <   0.36   <   St²/(St+0.25)² = 0.420   (St = 0.460)
```
범위 안에 들어간다. 본 다층 해석은 y, z 양방향 미러링을 모두 적용한다.

8. 주요 가정과 한계

1. **액적을 강체 구로 가정.** 실제로는 음향 복사압에 눌려 편평한 회전타원체가 되어
   정면 면적이 커지고 항력과 `A_cap` 이 모두 증가한다. `We = 0.008 ~ 0.208` 이므로
   유동에 의한 변형은 작지만 음향에 의한 변형은 무시하지 못한다.
2. **정상 유동 해석.** `Re_d ≳ 270` 의 비정상 와류이탈을 담지 못해 항력을 과소평가한다.
3. **Gor'kov 근사** `ka = 0.733`. 엄밀히는 산란장 기반 복사 응력 적분이 필요하다.
   기준 안티노드 2400 Pa 는 TinyLev 의 실측 부양 성능(2.2 g/cm³·4 mm)에 맞춰 잡은 값이며,
   구동 스윕 1680–3120 Pa 가 그 범위를 감싼다.
4. **액적 간 음향 산란 무시.** 기둥 안에서 액적들이 2.35 D 간격으로 늘어서 있어
   2차 Bjerknes 힘과 재산란이 실제로는 존재한다. `ka = 0.733` 에서 산란 단면적이
   작아 1차 근사로 무시했다.
5. **단방향 결합.** 음향 스트리밍(≈20 mm/s), 입자→유동 반작용, 액적 이동에 의한
   음향장 변화를 무시했다.
6. **덕트 벽 자유활동 + 처방 난류 프로파일.** 난류 모델을 풀지 않았다. 벽 근처
   액적(z = ±11.73 mm, 벽에서 1.64 D)의 항력·포집은 실제 난류 경계층에서 달라질 수 있다.
7. **입자 부착 = 접촉.** 접촉 시 100 % 부착으로 처리했다(젖음성 액적이므로 재비산 무시).
   액적 표면 액막의 입자 포화는 고려하지 않았다.
8. **증발 무시.** 장시간 운전에서는 직경 변화를 별도로 고려해야 한다.
9. **넥 공동을 자유활동 평면으로 근사.** 개구 위 전단층의 비정상 교환을 직접 풀지
   않았다(§3.1b). 교환유량이 직관의 0.21 % 로 작아 주유동에는 영향이 없지만,
   트랜스듀서 오염량의 상한은 별도 상관식 추정에 의존한다.
10. **덕트 바닥 침강을 필터 성능과 분리해야 한다.** 10 µm 입자는 6.03 mm/s 로
   가라앉아, U = 0.5~2.5 m/s 에서 입구 입자의 2.3~11.3 % 가 덕트 바닥에 침강한다.
   이는 액적 포집과 같은 자릿수이므로 반드시 나누어 보고한다(`neck_model.py`).##
